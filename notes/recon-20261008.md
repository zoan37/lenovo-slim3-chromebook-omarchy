# Recon, 2026-10-08 (ChromeOS 16805.31.0, M154, developer mode)

Collected from the developer-mode console as root over the LAN bridge.

## Identity

- `/proc/device-tree/model`: `Google Obiwan board`, compatible `google,obiwan`, `mediatek,mt8189`.
  The quigon variant uses the obiwan DTB; `mt8189-skywalker-obiwan.dts` is in the public `chromeos-6.6` branch.
- Firmware: RO `Google_Obiwan.16378.244.0`, RW `Google_Obiwan.16378.292.0`. Hardware write protect on (fine,
  firmware is not touched).
- 8 GB RAM (7883 MB visible), 15.4 GB zram swap under ChromeOS.

## Kernel

- `6.6.143-09592-gf1a210527406`, aarch64, built 2026-09-16, from the `chromeos-6.6` branch.
- KERN-A (`sda2`, 32 MB) is active (priority 2, successful), KERN-B is the fallback (priority 1).
- `futility show`: keyblock flags `!DEV DEV !REC !MINIOS`, RSA2048/SHA256 data key, body 0xe53000 bytes.
  Stock command line:
  ```
  console= loglevel=7 console_msg_format=syslog init=/sbin/init cros_secure drm.trace=0x106 root=/dev/dm-0
  rootwait ro dm_verity... dm="1 vroot none ro 1,0 6144000 verity payload=PARTUUID=%U/PARTNROFF=1 ..."
  noinitrd vt.global_cursor_default=0 kern_guid=%U cros_lsb_release_hash=... cpuidle.governor=teo
  irqchip.gicv3_pseudo_nmi=1
  ```
  `%U` is filled in by depthcharge with the kernel partition's GUID, so `root=PARTUUID=%U/PARTNROFF=1` points at
  the partition after whichever kernel partition booted.
- No `/proc/config.gz`; get the config from the `chromeos-6.6` source (`chromeos/config/chromeos/arm64/`).
- Filesystems: ext4, tmpfs, devtmpfs, cgroup + **cgroup2**, configfs, bpf, overlay built in; FAT/exFAT/NTFS3 as
  modules. ChromeOS itself mounts cgroup v1.
- LSMs: `capability,landlock,yama,loadpin,safesetid,chromiumos,selinux,bpf`. Plan: override with `lsm=` so
  LoadPin and the chromiumos LSM don't block modules/mounts from a non-verity root.
- **No VT, no fbcon**: `/dev/tty1`, `/dev/fb*`, `/sys/class/vtconsole` don't exist (ChromeOS's VT2 is frecon,
  in userspace). Boot will look black; debug via network and persistent journal.
- Modules `/lib/modules/6.6.143-…` 12 MB, firmware `/lib/firmware` 13 MB.

## Developer-mode flags

`dev_boot_usb=0`, `dev_boot_signed_only=0`, `dev_boot_altfw=0`, `mainfw_type=developer`. The developer keys are
on the device at `/usr/share/vboot/devkeys/` (`kernel.keyblock`, `kernel_data_key.vbprivk`), and `futility`,
`vbutil_kernel`, `cgpt`, `bsdtar`, `zstd`, `chroot`, `mkfs.ext4` are all in the ChromeOS image.
